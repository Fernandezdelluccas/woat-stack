# Histórias de usuário

| HU | Título | O que é |
|----|--------|---------|
| HU01 | Verificar atualização do projeto | Consultar se o repositório e as dependências estão em dia. |
| HU02 | Volume da música separado da acessibilidade | Separar no dock o grupo de acessibilidade (voz e tamanho de texto) do grupo de som (música e volume). |
| HU03 | Tradutor VLibras | Mostrar o widget oficial do VLibras em todas as páginas para traduzir o conteúdo para Libras. |
| HU04 | Ajuda de login clara | Deixar a ajuda da tela inicial aberta, com passos para quem já tem perfil e para o primeiro acesso, e atalhos para a área do professor e o modo de teste. |
| HU05 | Convite de professor pela diretoria | A diretoria gera um código `PROF-…` com turmas, usos e validade. O código é guardado só como hash. |
| HU06 | Cadastro real de professor | O professor cria conta com nome, e-mail, senha e código de convite, com confirmação por e-mail quando ativada no Supabase. |
| HU07 | Login com sessão salva | O professor entra com e-mail e senha e continua logado; o painel abre direto ao voltar. |
| HU08 | Concluir cadastro após confirmar e-mail | O professor com e-mail confirmado informa nome e código de convite para liberar o painel. |
| HU09 | E-mail para criar o código da turma (parcial) | Hoje só existe o e-mail de confirmação do cadastro, enviado pelo Supabase. O envio próprio ainda não foi definido nem implementado. |

Fora do escopo: recuperação de senha do professor.
